# Legal Source Folder

Put the local legal source document here as:

```text
data/legal/yasalar.pdf
```

The weekly Legal Guardian audit reads this file first. If the PDF is missing or cannot be read, the system falls back to the built-in listing checks.

For local testing without PDF analysis, you can also add:

```text
data/legal/yasalar.txt
```

Do not commit private legal documents or client material.
